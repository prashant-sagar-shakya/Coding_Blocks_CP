Welcome to my **Coding Blocks Competitive Programming** repository — a collection of algorithmic concepts, C++ implementations, mathematical techniques, and problem-solving approaches.

This repository brings together the foundations of competitive programming: from basic programming and complexity analysis to recursion, data structures, graph algorithms, greedy strategies, and dynamic programming.

The emphasis is on understanding why an algorithm works, when to use it, and how to implement it efficiently.

## 🧬 Algorithm Complexity Matrix

<div align="center">

| Complexity | Growth | Typical Example |
|:---:|:---|:---|
| `O(1)` | Constant | Array access |
| `O(log n)` | Logarithmic | Binary search |
| `O(n)` | Linear | Array traversal |
| `O(n log n)` | Linearithmic | Merge sort |
| `O(n²)` | Quadratic | Nested-loop algorithms |
| `O(2ⁿ)` | Exponential | Subset enumeration |
| `O(n!)` | Factorial | Permutation enumeration |

</div>

The objective is not merely to make a solution work. It is to understand its complexity, identify bottlenecks, and select an algorithm appropriate to the input constraints.

---

## 🧪 The engineering principles behind every solution

- **Correctness first:** A fast incorrect solution is still incorrect.
- **Complexity matters:** Input constraints guide algorithm selection.
- **Edge cases matter:** Boundary conditions are part of the problem.
- **Clarity matters:** Readable code is easier to reason about and debug.
- **Understanding matters:** Deriving a solution independently builds transferable skill.
